# Smart Counter App

A simple counter application developed using Flutter and Dart.

## Features
- Increment counter
- Decrement counter
- Reset counter
- Animated counter display
- Clean and user-friendly interface

## Technologies Used
- Flutter
- Dart
- Material Design

## How to Run
1. Install Flutter SDK.
2. Clone this repository.
3. Run `flutter pub get`.
4. Run `flutter run -d chrome`.
